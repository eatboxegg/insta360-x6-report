SCENE 01 / CONTROLLED

日常拍摄

小行星视角无人机跟拍感环境式自拍
WHAT FELT NEW

三个动作，拍出普通自拍难以实现的视角

  • 举过头顶：快速生成小行星视角，把人物和周围环境收进同一画面。
  • 肩扛隐形自拍杆：得到类似无人机跟拍的第三人称镜头，一个人也能边走边拍。
  • 低角度仰拍：让人物与树冠、高楼、天空同时入镜，普通自拍很难兼顾这种尺度。
IMAGE + THERMAL

近距离画质和高规格发热仍需取舍

  • 近距离虚焦：与手机在同一距离拍摄时更明显，不适合离主体太近。
  • 8K 30fps 发热：录制时尚可握持，但关机后散热较慢，会影响连续拍摄的信心。
CONTROL / Q BUTTON

使用频率不高，按压却不够顺手

日常拍摄很少用到 Q 键，它的位置和手感也不利于快速操作。如果它是屏幕失灵时的备用入口，需要更清楚地说明使用场景，并加强盲操作反馈。

WATERPROOF SAFETY

舱门没锁紧，却不容易被发现

充电口与电池仓的开关阻力偏小，比 Action 5 Pro 更容易误开。舱门留有缝隙时，相机仍无提示并可继续使用；用于潜水时，最好增加未锁紧检测和明确的防水警告。

REAL CONSTRAINT

看不到屏幕，也来不及重新构图

人群一直在移动，周围又有大量手机举起；嘉宾只会在局部位置短暂停留。拍摄者无法靠近，也很难保证镜头始终对准关键人物。

WHAT WORKED

只用举过人群，方向交给后期

把相机举高后，不用再判断嘉宾位于镜头哪一侧。360° 先保留周围画面，回看时再选择方向和画幅，减少拍错方向的风险。

UNIQUE VALUE

高位全景，无痛获得完整合影

相机举过人群后，一次就能把周围的人收进画面，不必现场反复站位、点人数或调整构图；活动结束后再从全景素材中选出合影。

LIMIT + OPPORTUNITY

全景能补方向，但穿不过人墙

人物如果被前排完全挡住，360° 也无法补回没有拍到的信息。更实际的做法是在拍摄前提示举高高度、检测遮挡，并建议使用延长杆或更换机位。

PAIN 01 / SETUP

能拍全场，
却架不稳

现场只能用胶带把延长杆粘在网柱上：固定慢、不够稳、拆卸麻烦，也缺少防坠保障。用户需要快速、稳定且不伤场地的标准机位。

PAIN 02 / MEMORY

好球刚打完，
时间点已忘

人在场上无法操作手机，继续打几个回合后便记不清高光发生在哪里。用户需要不打断比赛的一键标记。

PAIN 03 / EDITING

AI 剪得动，
却看不懂比赛

现有 AI 成片常出现重点不明、视角乱变、运镜随机；它识别了“运动”，却没有理解球、回合和叙事主角。用户需要懂球且可调整的初剪。

PAIN 04 / REPLAY

最想回看时，
视频还没准备好

争议球需要裁判视角，好球需要即时分享快乐；价值窗口发生在现场，而完整导出与剪辑发生在赛后。用户需要近两分钟即时回看。

PAIN 05 / PLACEMENT

第一次拍，
不知道放哪里

高度、网柱位置、顶灯眩光和球场范围都会影响结果，新用户只能反复试错。用户需要与运动类型匹配的机位指引。

PAIN 06 / LEARNING

好方法分散，
每个人重新踩坑

机位、参数和成片模板依赖玩家经验，却缺少针对具体运动的沉淀入口。用户需要可复用的社区经验与模板。

CORE USER NEED我需要的不只是一台记录相机，更是一个能帮我架好、记住、看懂并分享比赛的“球场搭子”。

HARDWARE ECOSYSTEM

硬件生态——先让相机真正站上球场

硬件要做的，是把现场临时用胶带固定、赛后凭记忆找时间点，变成稳定、顺手、可以重复的操作。

HARDWARE 01

网柱固定套环 / 绑带

把延长杆快速固定在球网两侧支柱上，得到高位、稳定、对称，又不占场边空间的机位。

为什么固定在网柱，而不是放在地上？地面机位高度不足，难以获得俯瞰全场的视角；大风环境下独立支架容易晃动或倾倒，也更容易被飞来的球击中、被场上人员碰倒。
01适配不同直径网柱，单手快速锁紧与拆卸
02防滑、减震与双重防坠，避免长时间拍摄位移
03高度和朝向可调，不损伤场地且不干扰比赛
04稳定性状态可视化，未锁紧时明确提醒

“精彩瞬间”遥控键

在现有蓝牙遥控器上增加醒目的实体按键。好球发生后随手一按，就能在时间轴上留下标记，不用暂停比赛或掏出手机。

01大按键、盲操作，支持腕带或夹在网柱旁

04多人可共同标记，标记次数可作为高光强度信号
SOFTWARE ECOSYSTEM

软件功能——从会拍到懂球

软件集中解决三个问题：第一次怎么拍、拍完去哪里学，以及长素材怎样变成看得懂的比赛内容。

01 / COURT MODE

专属模式与机位指引

选择运动类型后，根据球场、球网、顶灯和安全区域给出推荐网柱、安装高度与朝向，并用预览提示遮挡或眩光风险。

  • 排球 / 网球 / 羽毛球预设
  • 球场边界与球网自动校准
  • 推荐机位、视场范围与稳定性检查
02 / SPORTS COMMUNITY

运动影像社区

按运动和场馆整理机位、参数、模板与成片，让零散的个人经验变成搜得到、用得上的拍摄方法。

  • 机位与参数方案分享
  • 横屏复盘 / 竖屏高光模板
  • 同场双方共享素材与二创
03 / AI DIRECTOR

懂比赛的 AI 剪辑

不再随机追逐画面里的运动物体，而是先建立球场坐标、切分回合，确认用户想讲谁，再生成可以修改的镜头和节奏。

  • 多模态回合与高光识别
  • 全场 / 追球 / 主队 / 单人叙事
  • 所有镜头可调整、可撤销

AI EDITING LOGIC

AI 剪辑——先理解比赛，再决定镜头

这里展开软件功能 03：把画面、声音、遥控标记和比赛规则放在一起，先理解球场和回合，再生成镜头，避免通用 AI 一识别到运动就随意切镜。

00 / SPACE

建立球场坐标

识别边界与球网，确定有效运动空间、双方半场、可能球路与安全视场。

01 / AUDIO

定位击球声

利用每次击打形成的规律音频峰值，定位触球瞬间，并为 BGM 卡点提供节奏锚点。

02 / RALLY

自动划分回合

结合击球间隙、球落地、人员停顿；正式比赛再叠加哨声，生成可浏览的回合时间轴。

03 / INTENT

先选择叙事用途

用户决定是看完整战术、追踪球路、突出主队，还是锁定某位球员，AI 不替用户猜唯一答案。

04 / HIGHLIGHT

融合主客观高光

把遥控器标记与接球、扣球、拦网等动作识别结合，兼顾“算法认为精彩”和“用户觉得精彩”。

05 / CAMERA

生成可编辑运镜

跟随球路推进、转向和放大；关键动作前预留建立镜头，动作后保留队友反应，避免随机跳切。

CURRENT AI vs TARGET OUTPUT

同一段素材，两种理解

左侧是现有 AI 自动剪辑，说明“能生成”不等于“会讲比赛”；右侧是人工剪辑版本，为未来 AI 成片提供镜头和节奏参考。

CURRENT AI

剪得出来，但看不懂重点

重点不明：没有回合层级与关键动作判断
视角乱变：人物、球和全场之间缺少叙事理由
运镜随机：推进、转向与缩放没有服务于动作
TARGET AI

懂回合，才知道镜头该去哪

回合清楚：发球—组织—进攻—得分形成完整叙事
主角明确：根据用途突出球路、主队或关键球员
运镜有因：跟球推进，动作放大，高光后保留反应

人工版本不要求 AI 逐帧复刻，而是给出一套清楚的成片标准：每次切镜和运镜都要能回答“这一刻为什么看这里”。
